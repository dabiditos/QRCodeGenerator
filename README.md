# QRCodeGenerator
Aplicação simples para fazer códigos QR customizáveis, feita em Python.

Neste repositório estão um ficheiro Python e um executável.
Enquanto o ficheiro executável não precisa de "setup" nenhum para funcionar, para utilizar a aplicação Python é necessário seguir estes passos.
1. Criar um ambiente virtual (opcional)
2. Dentro da pasta do projeto, usar o comando "pip install segno" no terminal, para instalar a biblioteca do Python necessária.
3. Para correr, usar o comando "python qrCodeGen.py".
